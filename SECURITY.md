# Security Policy

## Scope

LexiDFA is an educational iOS app. The scanner processes the source text entered in the app locally; the project does not include a server or network API.

## Reporting a vulnerability

Please do not publish exploit details before the issue has been assessed. If private vulnerability reporting is enabled for the GitHub repository, use **Security → Report a vulnerability**. Otherwise, open a minimal issue asking for a private reporting channel and omit exploit payloads or sensitive data.

Reports should include the affected version, environment, reproduction steps, and potential impact. Do not send passwords, signing certificates, provisioning profiles, or private keys.

## Support status

Security fixes are considered for the current development branch. There is no guarantee of a particular response time or support window for older builds.
