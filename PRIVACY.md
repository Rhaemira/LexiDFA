# Privacy Policy

**Effective date:** 16 October 2026

LexiDFA is an educational lexical-analysis app maintained by Amirali Yazdani.

## Information processed by the app

Source code entered or pasted into LexiDFA is processed locally on the device for lexical analysis and visualization. The app does not send source code to a server.

The app stores a small number of preferences locally using Apple's `AppStorage` / `UserDefaults` APIs, including the selected appearance mode and whether C++ Grudge Mode is enabled. These preferences are not transmitted off the device.

## Data collection and tracking

The app does not include account creation, advertising, analytics, tracking, third-party runtime SDKs, or a network service. It does not collect or sell personal data through the app.

## Children's privacy

The app does not knowingly collect personal information from children because it has no account or data-collection service. Users should avoid entering personal or confidential information into sample source code.

## Changes

If the app's data practices change, this policy and the App Store privacy disclosures will be updated before the change is released.

## Contact

For privacy questions, use the maintainer contact associated with the LexiDFA GitHub repository.
